== Description ==
A lightweight, fast, and secure maintenance mode plugin for WordPress. Perfect for temporarily disabling your site while performing updates or maintenance.

== Features ==
* Enable/disable maintenance mode
* Custom title and message
* Background color option
* Exclude URLs
* Translation ready
* Lightweight and fast

== Installation ==
1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate via the 'Plugins' menu in WordPress
3. Go to Settings → WP Maintenance Lite
